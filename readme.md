# TechLearn Solutions — Padrões de Projeto

Atividade prática de Padrões de Projeto (GoF) em Java:

- **Singleton** — `LoggerService` (log centralizado)
- **Composite** — `ComponenteCatalogo`, `Aula`, `Modulo`
- **Iterator** — `Iterator`, `ModuloIterator`, `NullIterator`

## Como compilar

```bash
javac techlearn/logging/*.java techlearn/iterator/*.java techlearn/composite/*.java techlearn/Main.java
```

## Como executar

```bash
java techlearn.Main
```
